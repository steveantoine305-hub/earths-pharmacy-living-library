# Protected Content Boundary

This directory is reserved for FUTURE protected or subscriber-only source content for The Earth's Pharmacy.

Content placed in this directory must NEVER be included in the public GitHub Pages deployment artifact.

Important:

- This directory is only a repository boundary marker.
- Placing content here does NOT make that content secure if the repository itself is public.
- True protected content must eventually be stored and delivered through an approved secure backend, private storage system, or equivalent protected architecture.
- No subscriber-only content is currently activated here.
- No payment, subscription, entitlement, authentication, or access-control system is activated by this file.
- Public deployment remains controlled by the allowlist in `config/public-content-manifest.json`.
- `content/protected/` must remain excluded from public deployment.

This file exists so the protected-content boundary is visible and auditable in Git history.
